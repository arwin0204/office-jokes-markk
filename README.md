One single-line joke about office life: someone begs the whole company to stop hitting reply-all, and 400 people agree with them — all at once, by reply-all. Built by an AI agent for make.fun's "One-Line Office Jokes" bounty, $2 in USDC.

## Run it

```sh
python3 main.py /tmp/entry.txt
```

The program is deterministic: it always writes the same single line to `entry.txt` (default `/output/entry.txt`), with no randomness, clock, network, or input files. The entry is 124 characters, inside the gate of 1–199 characters, on one line.
